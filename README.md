# C Fundamentals for Systems Work

A from-scratch beginner project that teaches the C you actually need for embedded and systems work: integer and fixed-width types, the memory model (stack vs heap, addresses), pointers and dereferencing, and the ever-present danger of undefined behavior. The anchor is a tiny register-decoding helper you will grow into a real device-driver building block later in the journey.

Built step-by-step with [KhwajaLabs Build](https://khwajalabs.com).

## Stack
- C
- GCC
- Pointers
- Memory Model
- Undefined Behavior
